# Numbatt's Homebrew Tap

Personal Homebrew tap for tools by [@Numbatt](https://github.com/Numbatt).

## Available formulas

- [`gh-wallpaper`](https://github.com/Numbatt/github-heatmap-wallpaper) — your GitHub contribution heatmap as a macOS desktop wallpaper

## Install

One-time tap, then bare install:

```sh
brew tap Numbatt/tap
brew install gh-wallpaper
```

Or in one line:

```sh
brew install Numbatt/tap/gh-wallpaper
```

## Update

```sh
brew upgrade gh-wallpaper
```
